# Recursos para Inteligencia Artificial

Este documento contiene un mapeo de las herramientas, skills y recursos más útiles para trabajar con IA en este entorno.

## 🛠️ Mapping de Skills (Habilidades)

Aquí se detallan las habilidades instaladas en `.agents/skills/`, qué hacen y cuándo usarlas:

| Skill | Qué hace | Cuándo usarla |
| :--- | :--- | :--- |
| **browser-use** | Automatiza interacciones en el navegador (clics, formularios, capturas). | Navegación web compleja y extracción de datos. |
| **chrome-devtools** | Control e inspección profunda de un navegador Chrome en vivo. | Depuración web y análisis de rendimiento/red. |
| **code-review** | Revisa cambios de código buscando bugs, seguridad y calidad. | Antes de realizar un commit o durante PRs. |
| **excalidraw-diagram-generator** | Genera diagramas (flujo, arquitectura, mapas mentales) desde texto. | Visualizar procesos o sistemas rápidamente. |
| **frontend-design** | Crea interfaces web de alta calidad y estética cuidada. | Desarrollo de componentes UI, landing pages o apps. |
| **refactor** | Mejora la estructura del código sin cambiar su comportamiento. | Limpieza de código "sucio" o funciones muy largas. |
| **skill-creator** | Herramienta para crear, probar y optimizar nuevas habilidades. | Cuando necesites automatizar una tarea repetitiva nueva. |
| **systematic-debugging** | Framework para encontrar la causa raíz de errores sistemáticamente. | Ante bugs persistentes o fallos inesperados. |
| **webapp-testing** | Pruebas de aplicaciones web locales usando Playwright. | Testing de funcionalidad y depuración de UI local. |

## 🚀 Scripts y Herramientas Útiles

- **auto-skill.sh**: [Herramienta externa] Útil para la gestión automatizada de habilidades.
- **skill.sh**: [Herramienta externa] Utilidad para operaciones rápidas con skills.

## 🔗 Directorios de Servidores MCP

Para descubrir y gestionar servidores MCP (Model Context Protocol):

1.  **[Smithery.ai](https://smithery.ai)**: Una de las plataformas más populares para encontrar y configurar servidores MCP.
2.  **[Glama.ai (MCP)](https://glama.ai/mcp/servers)**: Excelente alternativa con un catálogo amplio y bien categorizado.
3.  **[Awesome MCP Servers (GitHub)](https://github.com/punkpeye/awesome-mcp-servers)**: Lista curada de servidores MCP mantenida por la comunidad.
4.  **[mcp-directory.com](https://mcp-directory.com)**: Directorio dedicado a la indexación de herramientas MCP.
